Отправить референс с iPhone

Телефон отправляет маленький JSON в iCloud Drive. Mac скачивает медиа, когда REF/VAULT запущен. Библиотека остаётся на Яндекс Диске.

Подключить папку

  1. Включи iCloud Drive на iPhone и Mac с одним Apple Account. На Mac папка iCloud Drive должна быть видна в Finder.
  2. В приложении «Файлы» открой iCloud Drive и создай папку REF-VAULT Inbox.
  3. Дождись, когда папка появится на Mac. Если доступна опция «Сохранять загруженным», включи её для этой папки.
  4. Запусти REF/VAULT. В разделе «С телефона» появится «Папка подключена». Если папка находится в другом месте, укажи её точный локальный путь в REF_VAULT_INBOX_DIR в .env проекта и перезапусти сервер.

Команда «REF/VAULT — быстро»

Создай новую команду в приложении «Команды». В сведениях включи «На странице экспорта» / «Показывать в меню Поделиться». Разреши входные типы: URL, веб-страницы Safari и текст. Названия действий могут немного отличаться в версии iOS.

  1. Получить URL из входных данных → входные данные команды.
  2. Получить элемент из списка → первый элемент найденных URL.
  3. Словарь: добавь ключ url с типом «Текст», а в значение вставь переменную первого URL. Для быстрого сохранения остальных полей не нужно.
  4. Получить текст из входных данных → словарь. Получится JSON. Используй словарь, чтобы кавычки и переносы строк в заметках корректно экранировались.
  5. Создать UUID → отдельное уникальное имя для каждого задания.
  6. Задать имя → текст из шага 4; имя — переменная UUID с суффиксом .json. Проверь, что имя заканчивается именно на .json, без .txt.
  7. Сохранить файл → файл с новым именем. Выбери iCloud Drive / REF-VAULT Inbox, отключи «Спрашивать, куда сохранить» и перезапись файлов. Если выбор постоянной папки недоступен, оставь запрос места сохранения и каждый раз выбирай Inbox.
  8. По желанию добавь уведомление «Отправлено в очередь REF/VAULT». Это подтверждает отправку JSON, а не скачивание медиа.

Команда «REF/VAULT — с заметкой»

Дублируй быструю команду. Перед словарём добавь три действия «Запросить ввод» с типом «Текст»: теги через запятую, заметка, коллекция. В словарь добавь текстовые ключи tags, note, collection со значениями из соответствующих запросов. Пустые значения допустимы. Без коллекции работа попадёт в «Inbox / Без разбора».

Проверить

  1. В Safari открой референс → «Поделиться» → команда REF/VAULT.
  2. В «Файлах» проверь наличие нового .json в iCloud Inbox. Открой его: должно быть поле url с полной ссылкой.
  3. После синхронизации на Mac очередь покажет «В очереди → Загружается → Сохранено». Появится карточка с локальными медиа. Если часть файлов не скачалась, статус будет «Сохранено · частично».
  4. Для проверки выключенного сервера останови REF/VAULT, отправь ещё одну ссылку, затем запусти сервер. Ожидающий файл подхватится автоматически.

JSON остаются в iCloud Inbox как журнал отправки. Один и тот же неизменённый файл повторно не обрабатывается. После успешного импорта его можно удалить через «Файлы»; это не удалит сохранённую работу. Ошибку загрузки можно повторить кнопкой в очереди. Если ошибся в JSON, исправь исходный файл — исправленная версия появится как новое задание.

Для первоначальной проверки можно положить такой файл с именем test.json:

{
  "url": "https://www.are.na/block/50913640",
  "tags": ["motion"],
  "note": "Тест импорта с телефона",
  "collection": ""
}

Команды необходимо один раз настроить на iPhone. Автоматическая подпись файла команды на этом Mac недоступна без входа в iCloud; неподписанный файл здесь не предлагается для установки.

Документация Apple: запуск через меню «Поделиться», словари, настройка iCloud Drive.
